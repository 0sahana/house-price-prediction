# House Price Prediction 🏠

This project uses Linear Regression to predict house prices using the Ames Housing Dataset.

## 📊 Features Used
- GrLivArea (Living Area)
- BedroomAbvGr (Bedrooms)
- FullBath (Bathrooms)
- GarageArea (Garage Size)

## ⚙️ Technologies
- Python
- pandas
- scikit-learn
- matplotlib
- seaborn

## 🚀 How to Run

```bash
pip install -r requirements.txt
python model.py
